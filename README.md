# Compile design course project

This repository contains the final project conducted for the course "Compiler design" as part of B.Sc degree in Computer engineering from Sharif university of technology.

The final result is an interpreter for the imaginary language C-. The project was implemented in 3 phases. In each phase, a stage of an interpreter analysis was implemented in the following order:

- Lexical analysis
- Syntax analysis (parsing)
- Semantic analysis

Aside from learning the structure and functioning concepts of compilers, the complexity of organizing the code was also a challenge in developing this project. In the end, the process of developing this project was a great practice in clean-code (variable naming, code separation, etc.)
